Jeview

What Jeview is

A visualizer for Jev that sits between your code and TypeSafe. Your requests come here instead of going to TypeSafe; Jeview sends each one on with your key, hands Jev's answer back, and keeps a copy to show you. It answers nothing itself.

Send Jev requests here

http://127.0.0.1:4777/v1/systemone

The same requests and answers as TypeSafe's address, with no key needed. To group requests under a project or label, add it to the path: /<label>/v1/systemone.

Link a call to the answer that led to it

Each answer comes back with an event id in events. Send it with a later call in a Jeview-Trigger header and the map grows that call off the answer. Jeview drops the header before calling Jev.

Where calls are kept

Nothing is stored anywhere else. Jeview runs on your computer, has no accounts and no tracking, and sends your requests to TypeSafe only.

For agents and scripts: llms.txt explains how to connect.
